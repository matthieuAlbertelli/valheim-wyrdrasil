# Wyrdrasil.Construction

Scaffold module for future blueprint capture, construction projects, PNJ-driven building, diagnostics, and testing utilities.

## Included in this scaffold
- Dedicated `Wyrdrasil.Construction` project
- Authoring, runtime, testing, diagnostics, persistence, bootstrap folders
- Public API surfaces for Registry and Routines integration
- Debug state and verbose construction logging service
- Minimal in-memory blueprint and project services
- Solution and project reference wiring for future integration

## Not implemented yet
- Real blueprint capture from Valheim pieces
- Piece placement in world
- Material reservation/consumption
- Routine occupation integration
- Registry actions and HUD integration
